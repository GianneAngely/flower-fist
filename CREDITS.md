# Credits & sources

## Bouquet photos
Picked from Pinterest search results (original files on i.pinimg.com), then:
1. **Google Flow (Nano Banana Pro)**: ribbons, twine and wrapping removed; bouquet placed on a solid blue screen; 2K upscale.
2. **Chroma key (local, Python)**: the blue screen is keyed out per pixel, including the gaps between stems, with blue spill removed from the edges.
3. Grip point and size are measured automatically so every bouquet is held by the stems and looks the same size in the hand.

Pinterest doesn't own these photos; copyright stays with the original creators. Fine for personal or local use. Before publishing, check the original sources or swap in freely licensed photos.

## Music
Playlist "WAVE TO EARTH SOFTPLAYLIST!" by kim! on Spotify. The player streams Spotify's official 30-second preview clips (`p.scdn.co`) and links each track to its full version on Spotify. No audio files are stored in this project.

## Tutorial hand photos
All five gestures were generated in Google Flow (Nano Banana 2.1) from one reference fist photo, so they show the same hand, skin tone and lighting, then keyed off a blue screen locally. Raw files are in `_raw/hands/`.

## Other
The reference fist was a stock photo; the generated versions have no watermark, but swapping in photos of your own hand before publishing is still the safest option.
